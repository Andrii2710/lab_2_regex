# lab_2_regex
# Лабораторна робота: Реалізація Regex Finite State Machine (Патерн State)

## Звіт до роботи
**Мета:** Закріпити знання про регулярні вирази, скінченні автомати (NFA) та реалізувати їх у коді.

У ході лабораторної роботи було створено спрощений компілятор регулярних виразів. Написаний рушій підтримує базовий синтаксис:
*   Будь-які ASCII символи - розпізнавання літер, цифр, пробілів та спецсимволів (через метод `.isascii()`).
*   Символ `.` - будь-який символ.
*   Квантифікатор `*` - нуль або більше повторень попереднього символу.
*   Квантифікатор `+` - одне або більше повторень попереднього символу.

## Пояснення імплементації
Архітектура базується на абстрактному класі `State`, від якого успадковуються конкретні стани автомату. 

**Основні вузли графа (стани):**
*   `AsciiState` / `DotState`: Перевіряють точний збіг символу або будь-який символ відповідно.
*   `StarState` / `PlusState`: Є станами-обгортками. Вони зациклюють граф на самих себе (додаючи `self` до `next_states`), що дозволяє реалізувати повторення.
*   `TerminationState`: Маркер успішного проходження стрічки.

**Алгоритм роботи (RegexFSM):**
1.  **Компіляція (`__init__`)**: Рядок з regex парситься посимвольно. Якщо зустрічається звичайний символ, він стає наступним вузлом. Якщо зустрічається модифікатор (`*` або `+`), він замінює попередньо доданий стан на себе, даючи попередньому символу можливість повторюватися
2.  **Валідація (`check_string`)**: Оскільки наявність `*` та `+` перетворює наш граф на недетермінований скінченний автомат (NFA), для валідації застосовується рекурсивна функція `match()`. Вона перевіряє всі можливі шляхи графу з використанням механізму backtracking та epsilon-переходів (безкоштовних кроків для `StarState`, який може спрацьовувати 0 разів).
